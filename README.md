# Pakistan Smart Traffic Intelligence 🚦

A computer vision-based traffic monitoring and analysis project built using Python, YOLO, OpenCV, NumPy, and Matplotlib.

## Overview

Pakistan Smart Traffic Intelligence analyzes traffic videos to detect and track vehicles, count different vehicle types, and visualize traffic movement.

The project explores how computer vision and data analysis can support smarter traffic monitoring systems.

## Features

- Vehicle detection using YOLO
- Vehicle tracking with ByteTrack
- Detection of cars, motorcycles, buses, and trucks
- Live vehicle counting
- Unique tracked vehicle ID counting
- Traffic motion analysis using OpenCV
- Numerical analysis using NumPy
- Traffic visualization using Matplotlib
- Processed video output with detection boxes

## Technologies Used

- Python
- OpenCV
- NumPy
- Matplotlib
- Ultralytics YOLO

## Installation

Clone the repository:

```bash
git clone https://github.com/shahadat-debug/pakistan-smart-traffic-intelligence.git
```

Install dependencies:

```bash
pip install opencv-python numpy matplotlib ultralytics
```

Place your traffic video at the path configured in the Python script.

Run the project:

```bash
python traffic_analyzer.py
```
